Analisis Dataset Happiness and Satisfaction :
Berkas dataset yang dilampirkan memuat berbagai indikator tingkat kesejahteraan sosial dan kondisi ekonomi global, seperti variabel Region untuk klasifikasi wilayah, Happy Score (0-10) untuk indeks kebahagiaan, GDP untuk kekuatan ekonomi, serta parameter pendukung berupa rata-rata kepuasan hidup (avg_satisfaction) dan pendapatan masyarakat (avg_income).
